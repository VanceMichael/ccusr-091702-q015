# 馆园共享资产交接网

本服务用于跨场馆与公园的资产流转和环境冻结。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：物品批次、封签、地点、交接、活动预留、环境告警、盘点差异、恢复包。

交接不可跳步且需要双方确认；离线事件不能造成双重位置；环境告警冻结相关流转；批量交接必须原子完成。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/shared_asset_custody.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
